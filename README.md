# e-learning-platform-testing
Manual Testing project for an E-Learning Platform including Test Plan, Test Cases, Bug Report, RTM and Test Summary Report.

## Project Overview

This repository contains manual testing artifacts for an E-Learning Platform. The project validates key functionalities such as user authentication, course enrollment, lesson access, quizzes, and progress tracking.

## Project Scope

- User Registration
- Login & Logout
- Forgot Password
- Course Search
- Course Enrollment
- View Lessons
- Video Playback
- Download Learning Resources
- Quiz Attempt & Submission
- Quiz Results
- Progress Tracking
- Profile Management

## Testing Types

- Functional Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Positive Testing
- Negative Testing

## Tools Used

- Microsoft Excel
- GitHub
